# Review the batch module

`batch.py` is a small module whose public functions each document their
contract. Exactly three of them violate it.

Read the module and write a structured review. For each defect report:

1. The name of the function it lives in.
2. The exact location of the defect (the expression, statement or default).
3. What the code does now and what it should do instead.

Cover all three defects: there is one off-by-one, one swallowed exception and
one wrong default. Do not modify any files; answer in your final message.
