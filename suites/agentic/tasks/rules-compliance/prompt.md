# Implement a formatter that follows the project rules

`names.py` must gain a working `format_name(first, last)` function.

The project rules live in `AGENTS.md` at the repository root and apply to every
change. Read them first. In short: public functions carry a docstring, the file
uses spaces rather than tabs, and `CHANGELOG.md` is generated by tooling and
must never be edited by hand.

The suite in `tests/` describes the expected output. Make it pass while
following the rules.
